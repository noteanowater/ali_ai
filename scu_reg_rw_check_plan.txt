SCU_REG 寄存器默认值 / 读写检查 —— 测试内容说明

【基本信息】
- 对应代码：scu_reg_rw_check_task.v
- 主 task：chip_top_task
- RTL 依据：SCU_REG.v（RELEASE DATE 2026/11/20）
- 访问方式：es_spi_master.ES_SPI_WR / ES_SPI_RD（SPI2APB）
- 基地址：0xA000_C000
- 写法：每次读写单独一行，期望值直接写在行内，可逐行修改。


【一、测试方法】
按地址顺序，每个寄存器做 3 步：
1. 读默认值，与 RTL reset 值比对。
2. 写 0xFFFF_FFFF。
3. 读回，期望值 = 默认值 | rw_mask（可写位读回 1，保留位 / 只读位保持原值）。
每个寄存器前有一行注释，标明默认值和可写位 rw_mask。
测试结束后不恢复默认值，寄存器的可写位保持全 1。


【二、寄存器分类】
1. 可读写寄存器（108 个）：读默认值 → 写全 F → 读期望值。
   其中 0x008 ~ 0x090 的 29 个（电源 / 系统模式 / 时钟门控 / IP 复位 / 晶振 / PLL / 分频）会真实改变芯片行为，
   写和回读两行放在 `ifdef SCU_RW_SYS 里，默认只读默认值不写。
2. 纯只读寄存器（27 个）：读默认值 → 写全 F → 读回值必须不变。
3. 只读默认值、不写的寄存器（19 个）：
   - 0x030：CPU_RESET / CHIP_RESET / SYS_RESET（写会复位芯片 / 释放 CPU 复位）
   - GMAC delay chain：0x1B8, 0x1BC, 0x1C0, 0x1C4, 0x1C8, 0x1CC, 0x1E0, 0x1E4, 0x1E8
   - EMMC delay chain：0x230, 0x234, 0x238, 0x23C, 0x240, 0x244, 0x248, 0x24C, 0x250
4. 未定义地址（16 个）：写全 F，读回必须为 0，用于检查地址译码。
   0x02C, 0x044, 0x04C, 0x09C, 0x0D0, 0x0D4, 0x0EC, 0x1A4, 0x1B0, 0x1D0, 0x1DC, 0x224, 0x22C, 0x284, 0x2BC, 0x2F0


【三、注意事项】
1. 假设 ES_SPI_RD(addr, exp) 的第二个参数是期望值，在 task 内部比对。
2. 0x028 / 0x050 / 0x054 / 0x058 的只读字段已按 rsim 实测值设置（0x0000_0007、0x3200_0701、0xA155_5555、0x0043_0053）；
   其余只读字段按 TB 输入全 0 计算，TB 有 tie 值时直接修改对应行的期望值。
3. 0x00C 默认值为 0x0001_0005（xip_en[16] 复位值为 1），不是 0x0000_0005。
4. 0x050 的 OSC 状态位（[29:24]）会随晶振起振变化，读的时刻不同结果可能不同。
5. 写全 F 后部分功能会被打开（如总线 timeout_en / error_resp_en、USB PHY 测试位、LVDS PRBS 等），且测试结束不恢复。
   如果 chip_top_task 之后还有其它测试，需要先把这些寄存器写回默认值。
6. 本文件定义了 chip_top_task，tb 中原有同名 task 需删除或改名。
