============================================================================
 GPIO chip-level pattern 测试内容说明        (chip_top_task.v)
============================================================================

一、测试对象
----------------------------------------------------------------------------
  gpio_top = 4 组 atcgpio100（GPIO0 ~ GPIO3，每组 32 通道）
  有 pad 的通道：GPIO_0 ~ GPIO_110，共 110 个（GPIO_39 没有 pad，不测）
  pad 观测/驱动点：test_chip_top.EXT_XGPIO_n
  gpio_top 路径  ：test_chip_top.chip_top.core_aon.apb_subsystem_aon.u03_gpio_top

  寄存器偏移：
    0x00 IdRev        0x10 Config       0x20 DataIn       0x24 DataOut
    0x28 ChannelDir   0x2C DoutClear    0x30 DoutSet      0x50 IntrEn
    0x54~0x60 IntrMode0~3               0x64 IntrStatus（写 1 清除）
    0x70 DebounceEn   0x74 DebounceCtl

二、检查方式
----------------------------------------------------------------------------
  寄存器读写全部直接调用 a45_io_write32b / a45_io_read32b，写在 chip_top_task
  里；逐通道测试时只写当前通道所在的那一组，其他组只配置一次。

  1. 寄存器检查：a45_io_read32b(base, offset, mask, expect) 自己比对并打印错误，
     不计入本 pattern 的汇总。
  2. pad 检查：直接看 EXT_XGPIO_n 的电平，x / z 也算错，计入汇总。
  3. 中断线检查：看 gpio_top 的 gpio_intr 输出，计入汇总。

三、测试步骤
----------------------------------------------------------------------------
Step 1  ID / 配置寄存器 / 复位值
  1    读 4 组 0x00、0x10
       期望：ID = 0x02031002，Config = 0x60000020
       发现：IP 版本或配置宏不对，地址映射错
  1-1  读 4 组所有可读写寄存器
       期望：全部为 0
       发现：复位值错、复位没连好

Step 2  PINMUX 选择 GPIO 功能
       PINMUX 0x00~0x50、0x5C 写 0x90909090；0x80~0xB0 写 0x01900190
       本步不检查；若没选到 GPIO（*_SEL_000），Step 4 会在 pad 上看到 z

Step 3  寄存器读写 / 4 组实例隔离
  3    0x28、0x50、0x70 写 A5A55A5A / 5A5AA5A5 / 0 并读回；
       0x54~0x60 写全 1 读回 0x77777777；0x74 写全 1 读回 0x800000FF；
       0x2C、0x30 读回 0
       发现：寄存器位宽、可写位不对，数据线粘连
  3-1  4 组写入不同的值，按 0->3 和 3->0 两种顺序各写一遍，全部读回
       期望：每组读回自己的值
       发现：APB 片选译码错，写一组时串写到另一组

Step 4  输出方向：GPIO -> PINPAD
  4    pad 由芯片驱动，全部设成输出，DataOut = 0
       期望：110 个 pad 全为 0
  4-1  walking-1：每次只让一个通道输出 1，每步检查全部 110 个 pad
       期望：只有对应的那个 pad 为 1
       发现：pad 与 GPIO 对应关系错（接反、接到别的 pad）、短路、输出恒 0
  4-2  walking-0：每次只让一个通道输出 0
       期望：只有对应的那个 pad 为 0
       发现：输出恒 1、两路粘连
  4-3  置位/清零：0x30 写 A5A5A5A5 -> 0x30 写 5A5A0000 -> 0x2C 写 0F0F00FF
       -> 0x2C 写全 1
       期望：pad 与 DataOut 依次为 A5A5A5A5 -> FFFFA5A5 -> F0F0A500 -> 0
       发现：置位/清零逻辑错
  4-4  方向位逐通道：DataOut 全 1，方向寄存器每次只设一个通道为输出
       期望：该通道的 pad 为 1
       发现：方向寄存器 bit n 没对应到通道 n

Step 5  输入方向：PINPAD -> GPIO
  5    全部设成输入，所有 pad force 为 0
       期望：DataIn 全为 0
  5-1  walking-1：每次只把一个 pad force 为 1
       期望：DataIn 只有对应的那一位为 1
       发现：输入对应关系错、输入恒 0
  5-2  walking-0：每次只把一个 pad force 为 0
       期望：DataIn 只有对应的那一位为 0
       发现：输入粘连、输入恒 1

Step 6  中断逐通道对应关系（上升沿模式）
  6    打开全部中断，每次只给一个 pad 上升沿 -> 写 1 清除该位 -> 下降沿
       期望：只有对应位置 1，gpio_intr = 1；清除后全 0，下降沿不触发，
             gpio_intr = 0
       发现：中断状态位对应错、顶层中断线没连、清除不生效
  6-1  中断使能逐通道：每次只使能一个通道，所有 pad 同时给上升沿
       期望：只有被使能的那一位置 1
       发现：中断使能 bit n 没对应到通道 n
  6-2  写 1 清除逐 bit：全部状态位置 1 后只清 bit n
       期望：只有 bit n 被清掉，其他位保持 1
       发现：清错位、清掉了整个寄存器

Step 7  中断触发模式（全部通道）
  每种模式：读回模式寄存器 -> 空闲电平不触发 -> 有效事件触发 ->
           保持有效电平写 1 清除（电平模式会重新置 1，边沿模式保持 0）->
           回到空闲电平（双沿再次触发，单沿反向边沿不触发）-> 清除后全 0
    高电平 (2)        空闲 0，有效 1
    低电平 (3)        空闲 1，有效 0
    上升沿 (6)        0 -> 1
    下降沿 (5)        1 -> 0
    双沿 (7) 先上升   0 -> 1 -> 0，两次都触发
    双沿 (7) 先下降   1 -> 0 -> 1，两次都触发
  7-1  模式 nibble 逐通道：通道 n 设上升沿，其余设下降沿；
       所有 pad 先上升再下降
       期望：上升时只有 bit n 置 1；下降时除 bit n 外全部置 1
       发现：中断模式第 n 个 nibble 没对应到通道 n
  发现：模式编码错、电平/边沿搞反、电平中断清除后不重新置位、边沿漏触发或多触发

Step 8  中断屏蔽 / 输出方向
  8    高电平模式，使能全关，pad 全拉高
       期望：状态全 0，gpio_intr = 0
       使能 = 0x55555555（只开偶数通道）
       期望：只有偶数位置 1
       发现：关掉使能后仍产生中断、屏蔽错位
  8-1  全部设成输出并输出 1，打开高电平中断
       期望：pad 为 1，但 DataIn 保持 0、不产生中断
       切回输入后：DataIn 变 1，中断置位
       发现：输出方向下仍在采样输入或产生中断；切回输入后不恢复

Step 9  Debounce（采样时钟用 pclk，0x74 bit31 = 1，上升沿中断判断边沿）
  准备 采样周期 256 pclk，全部通道打开 debounce
  9-1  所有 pad 给 128 拍高脉冲（短于一个采样周期）
       期望：DataIn 保持 0，无中断
       发现：毛刺没被滤掉
  9-2  所有 pad 拉高保持；131 拍时读一次，约 770 拍后再读
       期望：131 拍时仍为 0，之后变 1 并产生中断
       发现：没有去抖作用、或一直不通过
  9-3  高电平上给 128 拍低毛刺
       期望：DataIn 保持 1，无新中断
       发现：下降方向毛刺没被滤掉
  9-4  关掉 debounce，给 2 拍脉冲
       期望：中断置位（脉冲直接通过）
       发现：debounce 关不掉
  9-5  逐通道（采样周期 64 拍）：每次只打开通道 n 的 debounce，
       所有 pad 给 32 拍毛刺，再给长脉冲
       期望：毛刺时除通道 n 外都有中断，通道 n 被滤掉；长脉冲全部通过
       发现：debounce 使能 bit n 没对应到通道 n、单通道滤波失效
       （+define+GPIO_NO_DB_PER_CH 可关闭）
  9-6  可选（+define+GPIO_DB_EXTCLK_TEST）：用 extclk 作采样时钟，长脉冲能通过
       发现：extclk 没接或不翻转

Step 10 空洞地址
       先在 0x28、0x50、0x70 写哨兵值；
       4 组 0x00~0xFC 所有未定义地址
       （0x04~0x0C、0x14~0x1C、0x34~0x4C、0x68、0x6C、0x78~0xFC）
       写全 1 后读回
       期望：读回 0；哨兵值不变；0x24、0x74 为 0
       发现：地址译码不完整、写空洞地址别名到真实寄存器

四、结果判定
----------------------------------------------------------------------------
  仿真最后打印：
    GPIO TEST Summary : pad errors x, gpio_intr errors y (register read errors are reported by a45_io_read32b)
    GPIO TEST End : pad / gpio_intr checks PASS      （或 FAIL, N pad / gpio_intr errors）

  通过标准：
    - 看到 "GPIO TEST End : pad / gpio_intr checks PASS"
    - 并且 log 中没有 a45_io_read32b 打印的寄存器 Error
  没有出现 "GPIO TEST End" 这一行（仿真卡住或提前退出）应判为失败。
  tb 其他组件（BFM 超时、assertion 等）打印的 Error 也需要一起 grep。

五、开关
----------------------------------------------------------------------------
  +define+GPIO_NO_DB_PER_CH     跳过 Step 9-5 逐通道 debounce
  +define+GPIO_DB_EXTCLK_TEST   加跑 Step 9-6 extclk debounce
  +define+GPIO_NO_INTR_SIG      不检查 gpio_intr 输出线
  +define+GPIO_NO_RESET_CHK     跳过复位值检查
  +define+GPIO_TOP_PATH=...     修改 gpio_top 实例路径

六、未覆盖的范围
----------------------------------------------------------------------------
  - 只在检查点采样，两次检查之间的 pad / 中断线毛刺不会被发现
  - Step 4-4 只检查被设成输出的 pad，不检查其他 pad 未被驱动
  - 中断只检查到 gpio_top 的 gpio_intr，不含到中断控制器（PLIC）的路径
  - PINMUX 只验证 GPIO 功能（*_SEL_000），其他复用功能不在本 pattern
  - pslverr 未检查（gpio_top 中固定为 0）
  - PULL 功能未配置，不测
